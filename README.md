Репозиторий посвящен вкр на тему "Сравнение методов прогнозирования временных рядов для прогнозирования дебиторской задолженности".
Содержит две папки "notebooks" и "results".
В папке "notebooks" собраны 7 Jupyter-ноутбуков, в которых отображены:
 - разведочный анализ данных и проверка временных рядов на стационарность;
 - основной цикл обучения моделей и прогнозирования;
 - отдельный расчет метрики MAAPE;
 - визуализация полученных прогнозов;
 - обработка и визуализация метрик SMAPE, MASE, RMSSE;
 - проверка полученных различий на статистическую значимость;
 - предложенные сценарии по модификации текущего процесса прогнозирования.
В папке "results" содержатся файлы с прогнозами всех моделей по классам и исходному множеству временных рядов
и полученные оценки прогнозов.
